## Finding

Statement dataclasses from parser.py are frozen with eq comparing every field, `line` included, so `parse(lex(text)) != statements` is a layout-equality test, not a meaning test — it cannot be used to check meaning preservation across any reflow that changes line counts. The formatter's `_bare()` clears `line` at every depth (including inside PropertyRef, which `say card.title` carries) to compare meaning only. Separately: the lexer discards comments, so any formatOnSave formatter that re-emits from the parse tree alone deletes every comment in the file; format_program now returns a commented file untouched, and tests/test_formatter.py pins that.
