# Mission 77 — Visual backend theming system

Goal: the visual (tkinter) backend takes its spacing and theming from the
dictionary's machine-readable hints instead of hard-coded literals, and the
proposal for dictionary-driven *color* is written down for the commander —
because today's dictionary carries no color hints, and adding them is a
dictionary-schema change, not a backend detail.

          Note, for each of the four kinds, the `defaults.padding`,
