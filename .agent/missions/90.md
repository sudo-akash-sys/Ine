# Mission 90 — CLI enhancement audit.

Goal: the `ine` CLI is reviewed and improved with `--version`, a better
`--help`/subcommand structure, and an optional config file — with the current
flags' behavior unchanged, and the plan recorded in NOTES.

Files:
  - src/ine/cli.py       (edit)
  - src/ine/__init__.py  (edit: `__version__`)
  - tests/test_ine.py    (edit)
  - .agent/NOTES.md      (append one section)

Steps:
  1. [ ] Add `__version__ = "0.1.0"` to `src/ine/__init__.py` and a
          `--version` action on `main`'s parser (cli.py:48-73) printing
          `ine <version>` and exiting 0 (use `argparse`'s version hook or an
          explicit check before dispatch).
  2. [ ] Improve `--help`: keep the flat flags (`-o/--out`, `--native`,
          `--visual`, `--dict`) working exactly as today, but group the
          help text via `argparse`'s argument-group labels ("targets",
          "output", "dictionary") and note the default `output/<name>.html`
          behavior currently hidden in `_html` (cli.py:91-95). Do not rename
          or repurpose any existing flag.
  3. [ ] Add config-file support without disturbing the flag path: read
          `~/.config/ine/config.json` (or `INE_CONFIG` env override) for
          defaults that apply only when the corresponding CLI flag is absent;
          keep precedence CLI > env > file > built-in defaults. Implement in
          a small helper `_config_defaults()` used before `parse_args` /
          argument application.
  4. [ ] Document in NOTES `## Mission 90 — CLI audit` the planned subcommand
          structure for future growth (`ine run|render|native|visual|dict`
          with `format` reserved) and how far this mission went (flags +
          version + config; subcommand restructure is a follow-up, not done
          here — it would break existing invocations).
  5. [ ] Add tests: `--version` exits 0 and prints the version; `--help`
          exits 0 and mentions the default output behavior; config file
          defaults apply when the flag is absent and are overridden when the
          flag is present; existing `_html`/`_native`/`_visual` behavior is
          unchanged (CliErrorTests, test_ine.py:1605, still pass).

Verify: `python -m pytest tests/test_ine.py -q` — all pass, including
CliErrorTests and ReadmeQuickStartTests (README `ine --dict` forms still exit 0).
Done when: `ine --version`, `ine --help` behave, config defaults apply, and
the subcommand-devision plan is in NOTES.
