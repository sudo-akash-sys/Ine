# Mission 98 — Workbook reconciliation audit.

Goal: every WORKBOOK.md proposal is mapped to IMPLEMENTED / DECIDED /
PROPOSED / ABANDONED with gaps identified, recorded as a durable tracker in
NOTES — an investigation, no source changes.

Files:
  - .agent/NOTES.md        (append one section)
  - WORKBOOK.md            (read only)
  - LANGUAGE.md            (read only)
  - .agent/DECISIONS.md    (read only)
  - src/ine/               (read only)

Steps:
  1. [ ] Read WORKBOOK.md's section list and decisions (§1-§41 per STATE.md)
          and .agent/DECISIONS.md. Enumerate every distinct *proposal*
          (language construct, dictionary concept, tool/editor idea,
          packaging/CI item) — not every paragraph — into a list with its
          WORKBOOK section reference.
  2. [ ] Classify each proposal against the CURRENT implementation:
          - **IMPLEMENTED** — realized in src/ (e.g. `say`, entities,
            dictionary advisory, HTML rendering).
          - **DECIDED** — written in DECISIONS.md/LANGUAGE.md but not built
            (e.g. blocked/gated items with a commander ruling).
          - **PROPOSED** — still open, discussed but undecided (e.g. field
            kinds, `choice`, conditions/state).
          - **ABANDONED** — superseded or explicitly rejected (note where).
          Map each to the matching PLAN item number where one exists
          (BLOCKERS.md cross-references help).
  3. [ ] In NOTES `## Mission 98 — workbook reconciliation`, record the
          tracker as a markdown table (proposal | WORKBOOK section | status |
          PLAN item | notes). Then list the **gaps**: proposals with no PLAN
          mirror (orphan ideas) and IMPLEMENTED items that drift from their
          WORKBOOK wording.
  4. [ ] For each gap, name the follow-up action (new PLAN item, commander
          decision, or close-as-abandoned) but do NOT create PLAN items in
          this mission — the report lists them; the planner converts.
  5. [ ] Do not change LANGUAGE.md, DECISIONS.md, or any source — an audit's
          whole output is the NOTES report.

Verify: the tracker table covers every proposal cross-checked against
WORKBOOK headings; `git status` shows no src/ change.
Done when: NOTES has the full status table and the gap list with named
follow-ups.
Do not: modify WORKBOOK/LICENSE docs; implement anything; classify a proposal
as IMPLEMENTED without a concrete src/ reference.
