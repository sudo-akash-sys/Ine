# Mission 91 — Performance benchmarking suite.

Goal: a repeatable benchmark harness measuring lexer/parser/semantic analysis
and autocomplete latency across input sizes 10/100/1000 lines, with a
recorded baseline in `.agent/benchmarks/`.

Files:
  - .agent/benchmarks/bench.py   (new — durable harness)
  - .agent/benchmarks/BASELINE.md (new — recorded numbers)
  - src/ine/autocomplete.py       (read only)
  - tests/ — no change required

Steps:
  1. [ ] Create `.agent/benchmarks/bench.py`: a standalone Python script
          (no pytest) that generates Ine samples at 10 / 100 / 1000 lines
          (repeat `make card:` bodies + an `inside:` group so the files are
          semantically meaningful), then times, in repeated runs (min of 3):
          `ine.lexer.lex`, `ine.parser.parse`, `ine.semantic.analyze`,
          and `ine.autocomplete.complete` on a `{"validate": true}` query
          and one completion context. Print a compact table (lines;
          lex ms; parse ms; analyze ms; validate ms; complete ms).
  2. [ ] Make the harness deterministic and side-effect free: seeds the RNG,
          writes nothing outside .agent/benchmarks, and exits 0 only when all
          stages complete on all sizes (a crash is a nonzero exit + message).
  3. [ ] Store results in `.agent/benchmarks/BASELINE.md`: the machine
          (Windows/PowerShell/Python 3.13 per STATE.md), date, run command,
          and the full table — a durable record that a regression can be
          diffed against. Note explicitly that the numbers are for this
          machine and are comparative, not absolute.
  4. [ ] Add a comment-free `if __name__ == "__main__":` at the bottom and
          keep the script hermetic (no third-party deps — stdlib `time`,
          `random`, `statistics` only). Do not wire it into pytest (the main
          suite must stay fast and CI-free; this is a manual/operator tool).
  5. [ ] Re-run the harness after recording to confirm reproducibility
          (±20% on repeat is a caveat to note; a wildly different second run
          is a bug to chase).

Verify: `python -m .agent.benchmarks.bench` (or `python .agent/benchmarks/
bench.py`) runs to completion for all three sizes and matches the recorded
BASELINE within a stated tolerance.
Done when: BASELINE.md exists with a complete table, and a second run of the
harness reproduces it.
Do not: add pytest integration; add third-party dependencies (no timeit
wrappers requiring installs); modify src/; change the language.
