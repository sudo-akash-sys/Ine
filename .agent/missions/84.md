# Mission 84 — Editor diagnostics implementation.

Goal: a `.ine` file in VS Code shows red syntax underlines (lex/parse) and
**advisory** semantic findings (undeclared entity, double-parent, cycle) plus
hover text showing the dictionary `meaning` of the kind/property under the
cursor — with the `validate` query's lex+parse-only contract untouched.

Files:
  - src/ine/autocomplete.py     (edit)
  - tests/test_autocomplete.py  (edit)
  - editor/vscode-ine/extension.js  (edit)
  - editor/vscode-ine/package.json  (edit, if a command is added)

Steps:
  1. [ ] In `autocomplete.py`, add a `{"hover": true, "buffer", "line",
          "column"}` query beside `validate`: extract the token under the
          cursor in `buffer`, resolve it through `dictionary.find` / member /
          property lookup (`dictionary.suggest`, `dictionary.find`,
          `property_reference` helpers), and return
          `{"hover": True, "label", "meaning", "items": [...]}` where
          `meaning` is the dictionary entry's `meaning` field (e.g.
          `card.json` line 5) — or `{"hover": True, "label": None,
          "items": []}` when nothing resolves. Reuse `context(...)` / the
          buffer context helpers for token location. Never raise for a bad
          position; empty items is the fallback.
  2. [ ] Add an auxiliary semantic-check path feeding the same response
          shape as advisory diagnostics: run `analyze(parse(lex(buffer)))`
          and return one finding per `SemanticError` (undeclared entity,
          double-parent, cycle) as `{"line", "column"? , "message"}`. Do NOT
          change `_validate` (:224) — `validate` keeps its lex+parse-only
          contract (commander clarification, Session 41). Attach the
          findings under a distinct response key (e.g. `"advisory"`), and
          guard the whole semantic pass in try/except so a semantic crash
          degrades to `"advisory": []`.
  3. [ ] Extend `complete(payload)` (:248) to dispatch `validate` (unchanged),
          `hover`, and the advisory semantic check; keep `id` echo for all.
  4. [ ] In `tests/test_autocomplete.py`, add `HoverTests` next to
          `ValidateTests` (:619): hovering a kind token returns its `meaning`;
          hovering a blank/unknown position returns empty items; a semantic
          bug in the buffer (undeclared entity) returns the finding under
          `advisory` while `validate.diagnostics` stays lex+parse-only
          (parse-clean buffer that is semantically invalid → `[]` in
          diagnostics, finding under `advisory`).
  5. [ ] In `extension.js`, register a hover provider for the `ine` language
          (`vscode.languages.registerHoverProvider`) that calls the new hover
          query and returns a `Hover` with the meaning + suggestions, and a
          `DiagnosticCollection` refreshed on document change: query
          `validate` (unchanged) for lex/parse errors → red
          `DiagnosticSeverity.Error`; query the advisory semantic check →
          `DiagnosticSeverity.Warning` (advisory — semantic and dictionary
          findings are NEVER red-underlined). Clear the collection on close.
  6. [ ] If you added commands to `package.json`, keep them minimal and test
          them by hand in a local run (no editor CI harness exists yet — that
          is item 87).
