# Mission 123 — one external invocation and bounded runtime

Area: ine-agent
Depends on: 119
Goal: one model request per mission attempt, a hard wall-clock bound on every
subprocess, and honest per-cycle numbers.

## Why

When an attempt fails to classify, the supervisor spends a second request on
diagnosis and then, for a blocker, a third on a proposal. That multiplies cost
exactly when a mission is already in trouble. The usage report also presents
a global `opencode.db` total as if it were this run's cost, which is wrong for
any provider other than the one that happened to write the database.

## Files

- `src/ine_agent/worker.py` — timeout, output bound, metrics.
- `src/ine_agent/supervisor.py` — no diagnosis call; per-cycle reporting.
- `src/ine_agent/usage.py` — honest attribution.
- `tests/test_ine_agent.py` — timeout, no-second-call, and report tests.

## Steps

1. [x] In `worker.py`, give every subprocess a `timeout_seconds`. On expiry, kill
   the process, drain it, and return a result with exit code 124, the output
   collected so far, and `timed_out=True`. Apply the bound to both the
   streaming and non-streaming paths, and make the bound apply per mission
   attempt rather than to the whole run. — `TIMEOUT_EXIT_CODE = 124`,
   `CliWorker.timeout` honoured by both `_capture` and `_stream` (kill, drain,
   re-raise `_TimedOut` carrying the partial text), `_timed_out_result()`,
   built-ins 3600s (opencode) / 1800s (claude).
2. [x] Bound captured output: keep the head and the tail of a worker's output and
   discard the middle, so a runaway worker cannot flood the report, while the
   receipt at the end of the message is still parseable. Expose the cap as a
   constant and the retained size on the result. — `OUTPUT_LIMIT = 20000`,
   `OUTPUT_HEAD = 12000`, `bound_output()`; retained size is
   `result.metrics["output_chars"]`, measured after bounding.
3. [x] In `supervisor.py`, remove the automatic diagnosis call from the failure
   path. An unclassified failure becomes an explicit unknown status with the
   worker's own text, and the supervisor does not retry within the cycle. Keep
   `diagnosis_prompt` and `review_prompt` available for the planner and for
   humans, but stop calling `diagnose` from the run loop. A blocker that
   cannot be classified is recorded as unknown, not guessed at. — `_diagnose`
   reads the receipt, then the in-band line, then records `UNCLASSIFIED` with
   the worker's own text; no worker call. `Source.IN_BAND` added;
   `Source.FOLLOW_UP` / `Source.ERROR` kept so the trace stays readable.
4. [x] Record per cycle in the run report: mission number, exit code, prompt
   characters, prompt lines, output characters, elapsed seconds, and whether
   the attempt timed out. Print the same one-line summary to the console
   during the run. — `_cycle_metrics()` / `_print_cycle_metrics()`; the run
   also ends with `- this run (local): N worker invocation(s) ...`.
5. [x] In `usage.py`, report provider-reported usage separately from local
   measurements: if a global database total is present, label it as global and
   out of scope for this run rather than presenting it as this run's cost.
   Record the local prompt and elapsed numbers as the run's own measurement. —
   `format_snapshot(scope=...)` labels the database total
   "(global total for this machine — not this run's cost)"; new
   `format_local(cycles, elapsed_seconds)` leads with the invocation count.
6. [x] In `tests/test_ine_agent.py`: a worker script that sleeps longer than the
   timeout returns 124 with `timed_out` set and does not hang; a worker that
   prints a large body keeps head and tail and drops the middle; a failing
   worker triggers exactly one invocation; the run report contains the
   per-cycle metrics and does not present a global total as this run's cost. —
   `HANGING_PROBE` + `BoundedRuntimeTests` (14 tests). Existing tests whose
   call counts included a diagnosis call were updated to the halved counts.

## Finding

- The streaming path loses nothing: the live relay still carries every line
  (that is the no-deadlock property), and only the *retained* copy is bounded.
  Asserting on the relay rather than on `result.output` is what makes the
  deadlock test and the bound test independent.
- One invocation per attempt is only a real cost property if the *test
  doubles* are held to it too. Every `len(calls)` assertion in the suite was
  silently counting a diagnosis call; each was "missions + diagnoses" and
  became "missions".

## Constraints

- Do not silently drop the classification of a genuine blocker; report
  unknown rather than a guess.
- Keep the `--max-attempts` option; only its default changes, in mission 124.
- No Ine language changes.

## Done when

- [x] `pytest tests/test_ine_agent.py` passes (305) and a failing worker costs
  exactly one model request — `BoundedRuntimeTests` asserts one call, and the
  full suite (`643 passed, 33 subtests`) is green.
